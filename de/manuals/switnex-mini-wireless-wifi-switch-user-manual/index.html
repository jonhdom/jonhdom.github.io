SWITNEX Mini Wireless WiFi Switch User Manual

16.5.2026

SWITNEX Mini Wireless WiFi Switch Benutzerhandbuch

Technische Daten
Steuerungsmethoden Tuya APP, Amazon Alexa, Google Home, RF-Funkwands chalter
Maximale Last (Allgemein) 2500W
Maximale Last (LED/CFL/Leuchtstofflampen) 300W
Funkstandard Wi-Fi 2,4 GHz
RF-Frequenz 433MHz
Empfängerabmessungen 47 x 42 x 23 mm
Neustart-Status-Speicher Konfigurierbar (letzten Zustand merken)
Familienfreigabe Unterstützt

Produktdetail

  • 3 x Mini Wireless WiFi Relaisempfänger – kompaktes Design (47x42x23mm), Schraubklemmen für L/N-Eingang und -Ausgang
  • 1 x Funkwands chalter – mehrfach, RF 433MHz Steuerung
  • Pairing-Taste an jedem Empfänger – für Wi-Fi- und RF-Kopplung
  • Kontrollleuchte am Empfänger – zeigt Status und Kopplungsmodus an

Schaltplan

  • Stromversorgung: Schließen Sie Phase (L) an ‘L INPUT’ an, Neutralleiter (N) an ‘N INPUT’
  • Geräteausgang: Schließen Sie Phase (L) an ‘L OUTPUT’ an, Neutralleiter (N) an ‘N OUTPUT’
  • Montieren Sie den Empfänger in einem Elektroinstallationskasten mit ausreichender Belüftung

Warnung

  • Trennen Sie vor jeglichen Verdrahtungsarbeiten immer die Stromversorgung am Hauptsicherungskasten.
  • Bei Unsicherheit bezüglich der elektrischen Verkabelung konsultieren Sie einen qualifizierten Elektriker.
  • Überschreiten Sie nicht die maximale Last (2500W allgemein, 300W für LED/CFL/Leuchtstofflampen).
  • Stellen Sie sicher, dass das Wi-Fi-Netzwerk 2,4 GHz ist (5 GHz wird nicht unterstützt).
  • Halten Sie das Gerät von Wasser, Feuchtigkeit und extremen Temperaturen fern.

Betriebsmodus

RF-Funkwands chalter-Steuerung

Der Funkwands chalter kommuniziert über 433MHz RF mit dem Relaismodul.

So koppeln Sie:

  1. Stellen Sie sicher, dass das Relaismodul eingeschaltet ist.
  2. Halten Sie die Pairing-Taste am Relaismodul 3-5 Sekunden lang gedrückt, bis die Kontrollleuchte schnell blinkt.
  3. Drücken Sie innerhalb von 10 Sekunden eine beliebige Taste am Funkwands chalter.
  4. Die Kontrollleuchte hört auf zu blinken und leuchtet kurz durchgehend, was die erfolgreiche Kopplung bestätigt.

Mehrfachsteuerungsoptionen:

  • Mehrere Wands chalter können einen einzelnen Empfänger steuern
  • Ein Wands chalter kann mehrere Empfänger steuern

APP-Steuerung (Tuya Smart / Smart Life)

  1. Laden Sie die App Tuya Smart oder Smart Life aus Ihrem App Store (iOS/Android) herunter.
  2. Registrieren Sie sich oder melden Sie sich in Ihrem Konto an.
  3. Tippen Sie auf ’+’ oder ‘Gerät hinzufügen’.
  4. Wählen Sie ‘Elektrik’ > ‘Schalter (Wi-Fi)’ oder ‘Smart Switch’.
  5. Folgen Sie den Anweisungen in der App, um das Relaismodul mit Ihrem 2,4 GHz Wi-Fi-Netzwerk zu verbinden.
  6. Nach der Verbindung benennen Sie das Gerät um und steuern es von überall aus.

Sprachsteuerung (Amazon Alexa / Google Home)

  1. Öffnen Sie die Amazon Alexa- oder Google Home-App.
  2. Navigieren Sie zu ‘Skills & Spiele’ (Alexa) oder ‘Funktioniert mit Google’ (Google Home).
  3. Suchen Sie nach ‘Tuya Smart’ oder ‘Smart Life’ und aktivieren Sie den Skill/Dienst.
  4. Verknüpfen Sie Ihr Tuya/Smart Life-Konto, wenn Sie dazu aufgefordert werden.
  5. Entdecken Sie Geräte.
  6. Beispiele für Sprachbefehle:
    • „Alexa, schalte das Licht ein“
    • „Hey Google, schalte den Ventilator aus“

Zeitpläne und Timer

Legen Sie Zeitpläne, Countdowns und Schleifentimer für den automatischen Betrieb über die App fest:

  • Zeitplan: Legen Sie bestimmte Zeiten fest, zu denen Geräte ein-/ausgeschaltet werden
  • Countdown: Stellen Sie einen Timer ein, nach dem das Gerät ausschaltet
  • Schleifentimer: Wiederholen Sie Ein-/Aus-Zyklen in Intervallen

Neustart-Status-Speicher

Konfigurieren Sie das Gerät so, dass es sich nach einer Stromunterbrechung an seinen letzten Zustand erinnert (in der App konfigurierbar).

Familienfreigabe

Teilen Sie die Steuerung von Geräten mit Familienmitgliedern über die App.

Fehlerbehebung

Wenn der Empfänger und der Schalter nicht normal funktionieren, versuchen Sie die folgenden Schritte:

  • Modul verbindet sich nicht mit Wi-Fi: Stellen Sie sicher, dass es ein 2,4 GHz-Netzwerk ist (nicht 5 GHz). Überprüfen Sie das Passwort. Bewegen Sie sich während der Kopplung näher an den Router. Setzen Sie das Modul zurück und versuchen Sie es erneut.
  • Wands chalter reagiert nicht: Überprüfen Sie, ob das Modul mit Strom versorgt wird. Koppeln Sie den Schalter neu (Pairing-Taste 3-5 Sekunden drücken, dann Schaltertaste drücken). Stellen Sie sicher, dass Sie sich in RF-Reichweite befinden (bis zu 50 Meter im Freien).
  • App-Steuerung funktioniert nicht: Überprüfen Sie die Internetverbindung. Stellen Sie sicher, dass die Wi-Fi-Anzeige durchgehend leuchtet. Starten Sie die App neu.
  • Sprachsteuerung reagiert nicht: Überprüfen Sie die Kontoverknüpfung. Entdecken Sie Geräte erneut. Verwenden Sie die korrekten Gerätenamen.

Wartung

  • Halten Sie die Empfängermodule trocken und staubfrei. Verwenden Sie ein weiches, trockenes Tuch zur Reinigung.
  • Vermeiden Sie direkte Sonneneinstrahlung, hohe Luftfeuchtigkeit oder korrosive Umgebungen.
  • Überprüfen Sie regelmäßig die Verdrahtungsanschlüsse auf Sicherheit.
  • Sorgen Sie für ausreichende Belüftung, wenn sie in geschlossenen Räumen installiert werden.
