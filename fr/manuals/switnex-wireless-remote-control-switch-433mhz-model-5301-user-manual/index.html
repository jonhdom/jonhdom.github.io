SWITNEX Wireless Remote Control Switch 433MHz (Model 5301) User Manual

16 janvier 2026

Manuel d’utilisation de l’interrupteur sans fil SWITNEX 433 MHz (Modèle 5301)

Données techniques
Tension de fonctionnement (récepteur)DC 5V ~ 30V
Tension d’entrée/sortie (contacts relais)1V ~ 250V AC/DC
Type de sortieSortie passive (contacts sans potentiel)
Courant de repos<5MA
Courant maximal10A
Fréquence RF433MHz
Température de fonctionnement-30 ~ +80
Sensibilité de réception>97dbm
Nombre de télécommandes stockables20 pièces
Encodage supportéCode d’apprentissage 1527 (EV1527)
Mode de fonctionnement RFRéception sans fil superhétérodyne ASK
Portée de réceptionEspace libre de plus de 50 mètres
Mode de fonctionnement de la télécommandeMomentané / Bascule / Verrouillé / Temporisé
Piles de l’émetteur2 x CR2016 (incluses)
Dimensions du récepteur1,57 x 1,57 x 0,98 pouces

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Bouton d’apprentissage sur le récepteur – pour programmer les modes et réinitialiser
  • LED indicatrice sur le récepteur – fournit un retour visuel
  • Antenne sur le récepteur – à déployer pour une meilleure réception du signal
  • Boîtier du récepteur inclus
  • 2 x télécommandes porte-clés – chacune avec deux piles CR2016 préinstallées

Schéma de câblage

  • Entrée d’alimentation : Connectez du DC 5V-30V aux bornes +V (positif) et -V (négatif)
  • Sortie relais : NO (Normalement Ouvert), COM (Commun), NC (Normalement Fermé) – contacts secs
  • Pour un appareil qui s’allume lorsque le relais est activé : connectez entre NO et COM
  • Pour un appareil qui s’éteint lorsque le relais est activé : connectez entre NC et COM

Avertissement

  • Débranchez toujours l’alimentation avant d’effectuer tout câblage ou entretien pour éviter les chocs électriques.
  • Assurez-vous que la tension d’alimentation du récepteur est comprise entre DC 5V et 30V. Les contacts du relais gèrent des charges de 1V à 250V AC/DC, jusqu’à 10A.
  • Suivez attentivement les schémas de câblage. Un câblage incorrect peut endommager l’appareil ou l’équipement connecté.
  • Installez le récepteur dans un endroit sec et protégé, à l’abri de l’humidité excessive, de la chaleur ou des substances corrosives.
  • En cas de doute sur le câblage, consultez un électricien qualifié.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, reprogrammez-les.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de la télécommande est faible.
  • Étirez légèrement l’antenne du récepteur pour une meilleure réception du signal.

Mode de fonctionnement

Le mode par défaut est le Mode Verrouillé. Suivez les étapes de programmation ci-dessous pour changer de mode.

Mode Momentané (Mode 1)

Appuyez et maintenez un bouton enfoncé → le relais s’allume
Relâchez le bouton → le relais s’éteint

Comment programmer :

  1. Appuyez 1 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton souhaité de la télécommande. Le voyant clignotera rapidement puis s’éteindra. Réussi.

Mode Bascule (Mode 2)

Appuyez une fois sur un bouton → le relais s’allume
Appuyez à nouveau sur le même bouton → le relais s’éteint

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton souhaité de la télécommande. Le voyant clignotera rapidement puis s’éteindra. Réussi.

Mode Verrouillé (Mode 3)

Appuyez sur le bouton ON → le relais s’allume
Appuyez sur le bouton OFF → le relais s’éteint

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton ON de la télécommande.
  3. Appuyez sur le bouton OFF de la télécommande. Le voyant clignotera rapidement puis s’éteindra. Réussi.

Mode Temporisé (Modes 4/5/6/7)

Appuyez sur un bouton → le relais s’allume et reste allumé pendant une temporisation définie, puis s’éteint automatiquement

Options de temporisation :

  • Mode 4 (appuyez 4 fois sur le bouton d’apprentissage) : temporisation de 5 secondes
  • Mode 5 (appuyez 5 fois sur le bouton d’apprentissage) : temporisation de 10 secondes
  • Mode 6 (appuyez 6 fois sur le bouton d’apprentissage) : temporisation de 15 secondes
  • Mode 7 (appuyez 7 fois sur le bouton d’apprentissage) : temporisation de 20 secondes

Comment programmer :

  1. Appuyez le nombre de fois souhaité sur le bouton d’apprentissage (4, 5, 6 ou 7). Le voyant clignotera.
  2. Appuyez sur le bouton souhaité de la télécommande. Le voyant clignotera rapidement puis s’éteindra. Réussi.

Réinitialisation

Appuyez 8 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera rapidement puis s’éteindra, indiquant que tous les codes stockés ont été effacés. Après la réinitialisation, reprogrammez vos télécommandes.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Télécommande ne fonctionne pas après la configuration : Assurez-vous que le bouton d’apprentissage a été pressé le bon nombre de fois et que le bouton de l’émetteur a été pressé pendant que le voyant clignotait. Si le récepteur a été réinitialisé (8 pressions), reprogrammez les émetteurs.
  • Portée de contrôle réduite : Vérifiez les piles de l’émetteur (remplacez-les par des CR2016 neuves). Les murs épais ou les structures métalliques peuvent réduire la portée. Déployez l’antenne du récepteur.
  • Le relais ne s’active pas : Vérifiez l’alimentation du récepteur (DC 5V-30V). Vérifiez le câblage des bornes NO/COM/NC. Assurez-vous que la tension et le courant de la charge sont dans les spécifications du relais (1V-250V AC/DC, max 10A).
  • Le voyant ne clignote pas : Assurez-vous que le récepteur est alimenté. Vérifiez les connexions de câblage.
  • Interférences : D’autres appareils 433 MHz ou des champs électromagnétiques puissants peuvent causer des problèmes. Essayez de déplacer le récepteur.

Entretien

  • Nettoyage : Essuyez le récepteur et les émetteurs avec un chiffon doux et sec. N’utilisez pas de produits chimiques agressifs ou de nettoyants abrasifs.
  • Remplacement des piles (émetteur) : Chaque télécommande utilise deux piles CR2016. Lorsque la portée diminue ou que la LED est faible, ouvrez le boîtier, remplacez les piles en respectant la polarité, refermez soigneusement.
  • Conservez les appareils dans un environnement sec et sans poussière.
