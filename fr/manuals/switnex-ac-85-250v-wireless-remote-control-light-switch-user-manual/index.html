SWITNEX AC 85-250V Wireless Remote Control Light Switch User Manual

16 janvier 2026

SWITNEX AC 85-250V Manuel d’Utilisation de l’Interrupteur Sans Fil

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Bouton d’apprentissage sur le récepteur – pour programmer les modes et réinitialiser
  • LED indicatrice sur le récepteur – fournit un retour visuel
  • Antenne sur le récepteur – à déployer pour une meilleure réception du signal
  • 2 x Émetteurs télécommande – avec pile 27A 12V incluse
  • Connecteurs de câblage (si applicable)

Schéma de câblage

  • Bornes d’entrée : Connectez la phase (L) et le neutre (N) CA 90V-250V de la source d’alimentation
  • Bornes de sortie : Connectez la phase (L) et le neutre (N) à l’appareil (ex. : ampoule)

Avertissement

  • Débranchez toujours l’alimentation avant l’installation ou l’entretien pour éviter les chocs électriques. L’installation doit être effectuée par un électricien qualifié ou conformément aux codes électriques locaux.
  • Assurez-vous que la tension d’entrée (CA 90V-250V) correspond à votre système électrique.
  • Ne dépassez pas la capacité de charge maximale de 1500W ou 10A.
  • N’exposez pas le récepteur à l’humidité, aux températures extrêmes ou aux environnements corrosifs. Le récepteur n’est pas étanche sauf indication contraire explicite.
  • Gardez l’appareil et les télécommandes hors de portée des enfants et des animaux domestiques.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, veuillez les reprogrammer.
  • Réinitialisez avant de changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur est faible.
  • Déployez légèrement l’antenne sur le récepteur pour une meilleure réception du signal.

Mode de fonctionnement

Le produit est préconfiguré en mode Verrouillé. Vous pouvez changer de mode en suivant les étapes de programmation ci-dessous.

Mode Momentané

Appuyez et maintenez un bouton → la sortie est active
Relâchez le bouton → la sortie s’éteint

Comment programmer :

  1. Appuyez 4 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton A de votre télécommande.
  3. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Momentané.

Mode Bascule

Appuyez une fois sur un bouton → la sortie s’allume
Appuyez à nouveau sur le même bouton → la sortie s’éteint

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton B de votre télécommande.
  3. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Bascule.

Mode Verrouillé

Appuyez sur le bouton A → la sortie s’allume
Appuyez sur le bouton B → la sortie s’éteint

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton A de votre télécommande (pour ALLUMER).
  3. Appuyez sur le bouton B de votre télécommande (pour ÉTEINDRE).
  4. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Verrouillé.

Définir l’état par défaut (Allumé/Éteint)

Pour définir si le relais est par défaut ALLUMÉ ou ÉTEINT lors du rétablissement de l’alimentation :

  1. Appuyez 7 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Le récepteur basculera entre les états par défaut ALLUMÉ et ÉTEINT. Le voyant confirmera l’état par défaut sélectionné.

Réinitialisation

Pour effacer tous les codes de télécommande stockés dans le récepteur, appuyez 8 fois sur le bouton d’apprentissage. Le voyant clignotera, confirmant que tous les codes ont été effacés.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • L’appareil ne répond pas à la télécommande : Vérifiez que le récepteur est correctement alimenté (voyant allumé). Assurez-vous que la pile de la télécommande n’est pas déchargée. Vérifiez que la télécommande est correctement appairée. Effacez tous les codes et reprogrammez si nécessaire. Vérifiez les obstructions ou une distance excessive.
  • L’appareil s’allume/s’éteint de manière inattendue : Cela peut être dû à des interférences. Essayez d’effacer tous les codes et de réappairer. Assurez-vous qu’aucun autre appareil 433 MHz ne fonctionne à proximité.
  • Le voyant du récepteur ne s’allume pas : Vérifiez l’alimentation électrique et les connexions de câblage. Vérifiez que le disjoncteur n’est pas déclenché.

Entretien

Remplacement de la pile (télécommande) : La télécommande utilise une pile 27A 12V. Si le voyant ne s’allume pas ou si la portée diminue :

  1. Ouvrez soigneusement le boîtier de la télécommande.
  2. Retirez l’ancienne pile 27A 12V.
  3. Insérez une nouvelle pile 27A 12V en respectant la polarité.
  4. Refermez le boîtier solidement.

Nettoyage : Essuyez le récepteur et la télécommande avec un chiffon sec et doux. N’utilisez pas de nettoyants liquides ou de solvants.
