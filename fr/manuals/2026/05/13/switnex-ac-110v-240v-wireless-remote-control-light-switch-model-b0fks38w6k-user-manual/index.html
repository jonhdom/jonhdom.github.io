SWITNEX AC 110V-240V Wireless Remote Control Light Switch (Model: B0FKS38W6K) User Manual

13 janvier 2026

Manuel d’utilisation de l’interrupteur sans fil SWITNEX AC 110V-240V (Modèle : B0FKS38W6K)

Données techniques
Mode de fonctionnement ON-OFF
Courant nominal 10 Ampères
Tension de fonctionnement AC 90V-250V (compatible 110V, 120V, 220V, 240V)
Charge maximale (résistive) 1500W
Type de contact Normalement ouvert
Type de connecteur Sertissage
Borne Vis
Dimensions du récepteur (L x l x H) 65 x 36 x 23 mm
Dimensions de l’émetteur (L x l x H) 115 x 70 x 15 mm
Type de circuit 1 voie
Matériau de contact Plastique
Fréquence RF 433 MHz
Distance de contrôle (zone dégagée) Jusqu’à 30 mètres
Distance de contrôle (à travers murs/portes) 30-55 mètres
Pile de l’émetteur 1 x AAA 12V (incluse)

Détail du produit

  • Récepteur relais RF – unité compacte (65x36x23mm), bornes d’entrée/sortie (L et N)
  • 2 émetteurs de télécommande – style porte-clés avec boutons ON/OFF
  • 1 pile AAA 12V – préinstallée dans l’émetteur
  • Ruban adhésif double face – pour le montage de l’émetteur
  • Vis – pour le montage de l’émetteur
  • Bouton d’apprentissage sur le récepteur – pour les modes de programmation et la réinitialisation
  • Voyant lumineux sur le récepteur – fournit un retour visuel

Schéma de câblage

  • Entrée : Connectez l’alimentation AC 90V-250V aux bornes d’entrée (Phase ‘L’ et Neutre ‘N’)
  • Sortie : Connectez l’appareil (ex. : lampe, ventilateur) aux bornes de sortie
  • Scénario A : Récepteur en série avec le fil de phase (L)
  • Scénario B : Récepteur en série avec le fil de neutre (N)

Avertissement

  • Débranchez toujours l’alimentation au niveau du disjoncteur avant d’installer ou d’entretenir le récepteur.
  • L’installation doit être effectuée par un électricien qualifié ou conformément aux codes électriques locaux.
  • Ne dépassez pas la capacité de charge maximale de 1500W (charge résistive 10A).
  • Assurez-vous que la tension de fonctionnement (AC 90V-250V) est compatible avec votre système électrique.
  • Tenez l’appareil à l’écart de l’eau et des environnements très humides.
  • N’essayez pas de démonter ou de modifier l’appareil.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, reprogrammez-les.
  • Réinitialisez avant de changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur est faible.

Mode de fonctionnement

Le produit est préréglé par défaut en Mode Verrouillé. Suivez les étapes de programmation ci-dessous pour changer de mode.

Mode Momentané

Appuyez et maintenez un bouton → l’appareil s’allume
Relâchez le bouton → l’appareil s’éteint

Comment programmer :

  1. Appuyez 4 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton souhaité de l’émetteur. Le voyant clignotera pour confirmer.

Mode Bascule

Appuyez une fois sur un bouton → l’appareil s’allume
Appuyez à nouveau sur le même bouton → l’appareil s’éteint

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton souhaité de l’émetteur. Le voyant clignotera pour confirmer.

Mode Verrouillé

Appuyez sur le bouton ON → l’appareil s’allume
Appuyez sur le bouton OFF → l’appareil s’éteint

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton ON de l’émetteur. Le voyant clignotera.
  3. Appuyez sur le bouton OFF de l’émetteur. Le voyant clignotera pour confirmer.

Réinitialisation

Pour effacer tous les émetteurs appairés de la mémoire du récepteur, appuyez 8 fois sur le bouton d’apprentissage. Le voyant clignotera rapidement puis s’éteindra, indiquant que toutes les données stockées ont été effacées. Après la réinitialisation, réappairez les émetteurs si nécessaire.

Installation de l’émetteur

  • Mode fixe : Montez sur un mur ou une surface plane à l’aide du ruban adhésif double face (non permanent) ou de vis (sécurisé). Ouvrez le boîtier pour accéder aux trous de montage et au compartiment de la pile.
  • Mode portable : Utilisez comme télécommande portable depuis n’importe où dans la portée.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • L’appareil ne répond pas : Vérifiez le câblage et l’alimentation du récepteur. Assurez-vous que la pile de l’émetteur fonctionne (remplacez-la si nécessaire). Réappairez l’émetteur et le récepteur. Vérifiez que l’appareil connecté fonctionne lorsqu’il est alimenté directement.
  • Portée de contrôle réduite : Retirez les obstructions métalliques. Ne placez pas le récepteur dans des boîtiers métalliques. Évitez les interférences RF fortes provenant d’autres appareils.
  • L’émetteur ne fonctionne pas : Remplacez la pile AAA 12V. Assurez-vous de la polarité correcte.

Entretien

  • Nettoyage : Essuyez les appareils avec un chiffon doux et sec. N’utilisez pas de produits chimiques agressifs ou de nettoyants abrasifs.
  • Remplacement de la pile : L’émetteur utilise une pile AAA 12V. Ouvrez soigneusement le boîtier, remplacez la pile en respectant la polarité.
  • Stockage : Conservez dans un endroit frais et sec, à l’abri de la lumière directe du soleil et des températures extrêmes.
