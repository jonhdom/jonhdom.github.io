SWITNEX DC 12V Wireless Relay Remote Control Switch User Manual

10 janvier 2026

Manuel d’utilisation du commutateur relais sans fil SWITNEX DC 12V

Données techniques
Numéro de modèle 1204
Tension d’entrée / sortie 1V-250V
Tension de fonctionnement DC 12V
Courant nominal 10 Ampères
Fréquence RF 433MHz
Sensibilité de réception >97dBm
Code de puce EV1527 (Code d’apprentissage)
Portée de la télécommande Jusqu’à 50 mètres (zone dégagée)
Nombre de relais 4
Durée de vie du relais Plus de 100 000 utilisations
Type de connecteur Borne à vis
Matériau de contact Alliage de cuivre
Type de contact Normalement fermé (NF), Commun (COM), Normalement ouvert (NO)
Type de montage Montage en surface
Dimensions du produit 2,95 x 2,17 x 1,18 pouces
Poids du produit 5,93 onces
Piles (émetteurs) 2 piles CR2 (incluses)

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée

Schéma de câblage

Avertissement

  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, veuillez les reprogrammer.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur est faible pour obtenir une transmission de signal plus forte.
  • Étirez légèrement l’antenne du récepteur pour une meilleure réception du signal.
  • Assurez-vous que l’alimentation est coupée avant d’effectuer toute connexion de câblage.
  • Le type de sortie est une sortie passive / contacts sans potentiel.

Mode de fonctionnement

Mode Momentané

Appuyez et maintenez un bouton → le relais correspondant s’allume
Relâchez le bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 1 fois. Le voyant LED du récepteur s’allumera.
  2. Appuyez sur le bouton souhaité (par exemple, ‘A’) sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Bascule

Appuyez sur un bouton → le relais correspondant s’allume
Appuyez à nouveau sur le même bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 2 fois. Le voyant LED s’allumera.
  2. Appuyez sur le bouton souhaité sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Verrouillé

Appuyez sur le bouton ‘A’ → Le relais 1 s’allume (Le relais 2 s’éteint s’il était allumé)
Appuyez sur le bouton ‘B’ → Le relais 2 s’allume, et le relais 1 s’éteint en même temps

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 3 fois. Le voyant LED s’allumera.
  2. Appuyez sur le bouton souhaité sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Mixte

Pour des configurations avancées (par exemple, 2 momentanés + 2 bascules ; 2 momentanés + 2 verrouillés ; 2 bascules + 2 verrouillés), appuyez sur le bouton d’apprentissage 4, 5 ou 6 fois respectivement, puis appuyez sur les boutons correspondants de la télécommande comme indiqué.

Réinitialisation

Appuyez sur le bouton d’apprentissage (sur le récepteur) 8 fois. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi. (Tous les émetteurs appairés seront effacés.)

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Vérifiez si la pile est épuisée. Le voyant LED de l’émetteur ne s’allume pas ou est faible. Remplacez par des piles CR2 neuves.
  • Vérifiez si votre récepteur est correctement câblé. Assurez-vous que le câblage vers les bornes NC, COM, NO est correct.
  • Assurez-vous que le récepteur est à portée (jusqu’à 50 mètres en zones dégagées) et que l’antenne n’est pas obstruée.
  • Évitez de placer le récepteur près d’autres sources de signaux RF puissantes qui pourraient causer des interférences.
  • Reprogrammez le récepteur et l’émetteur. Cela peut généralement résoudre de nombreux problèmes.
  • Si le problème persiste, veuillez nous contacter.
