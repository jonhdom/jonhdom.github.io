SWITNEX Wireless DC Motor Remote Control Switch User Manual

10 janvier 2026

Manuel d’utilisation de l’interrupteur sans fil pour moteur à courant continu SWITNEX

Données techniques

Charge maximale (résistive)10 Ampères
Charge maximale (inductive)5 Ampères
Fréquence433 MHz
Modes de fonctionnementMomentané, Bascule, Verrouillé

Détail du produit

  • Bouton d’apprentissage sur le récepteur – pour programmer les modes de fonctionnement et réinitialiser
  • Voyant lumineux sur le récepteur – fournit un retour visuel

Schéma de câblage

  • Entrée : Alimentation CC 12V-80V (rouge : positif, noir : négatif)
  • Sortie : Vers le moteur à courant continu (rouge : positif du moteur, noir : négatif du moteur)
  • Pour les applications de treuil : Voir le schéma de câblage du relais solénoïde spécialisé pour treuil.

Avertissement

  • Assurez-vous que la tension de l’alimentation correspond à la plage de tension spécifiée du récepteur (CC 12V-80V).
  • Ne dépassez pas la charge résistive maximale de 10A (charge inductive 5A) pour le relais.
  • Débranchez l’alimentation avant d’effectuer tout câblage ou entretien pour éviter les chocs électriques.
  • Gardez l’appareil à l’écart de l’eau et des environnements très humides.
  • N’essayez pas de démonter ou de modifier l’appareil, car cela pourrait annuler la garantie et présenter des risques de sécurité.
  • Ce produit est destiné à être utilisé uniquement avec des moteurs à courant continu.

Mode de fonctionnement

Le produit est généralement préprogrammé en mode Verrouillé. Vous pouvez changer le mode en suivant les étapes de programmation ci-dessous.

Mode Momentané

Appuyez et maintenez le bouton Haut (▲) → le moteur fonctionne en avant
Relâchez le bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 1 fois. Le voyant lumineux clignotera une fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant lumineux clignotera, confirmant la programmation réussie.

Mode Bascule

Appuyez une fois sur le bouton Haut (▲) → le moteur démarre (en avant)
Appuyez à nouveau sur le même bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 2 fois. Le voyant lumineux clignotera deux fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant lumineux clignotera, confirmant la programmation réussie.

Mode Verrouillé

Appuyez sur Haut (▲) → le moteur tourne en avant
Appuyez sur Bas (▼) → le moteur tourne en arrière
Appuyez sur Arrêt (■) → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 3 fois. Le voyant lumineux clignotera trois fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur (programmer la rotation avant).
  3. Appuyez sur le bouton Bas (▼) de l’émetteur (programmer la rotation arrière).
  4. Appuyez sur le bouton Arrêt (■) de l’émetteur (programmer la fonction d’arrêt). Le voyant lumineux clignotera, confirmant la programmation réussie.

Changer la direction du moteur (Avancé)

Si le moteur tourne dans le sens opposé à la direction souhaitée pour les boutons Haut/Bas, appuyez sur le bouton d’apprentissage 7 fois. Cela inversera la polarité de sortie.

Réinitialisation

Pour effacer tous les émetteurs programmés et réinitialiser le récepteur à l’état par défaut, appuyez sur le bouton d’apprentissage 8 fois. Le voyant lumineux clignotera pour confirmer. Après la réinitialisation, aucune télécommande ne pourra faire fonctionner le récepteur jusqu’à ce qu’elle soit reprogrammée.

Entretien

  • Gardez le récepteur et les émetteurs propres et secs.
  • Vérifiez régulièrement les connexions de câblage pour détecter tout desserrage ou corrosion.
  • Remplacez les piles de l’émetteur lorsque le voyant lumineux s’affaiblit ou que la portée diminue. Les émetteurs utilisent des piles 12V.
  • N’exposez pas les appareils à des températures extrêmes ou à la lumière directe du soleil pendant des périodes prolongées.
