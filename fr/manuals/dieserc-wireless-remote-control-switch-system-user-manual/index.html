DieseRC Wireless Remote Control Switch System User Manual

13 janvier 2026

Manuel d’utilisation du système d’interrupteur sans fil DieseRC

Données techniques
Marque DieseRC
Modèle RX26
Tension de fonctionnement (récepteur) CC 3,6 V ~ 30 V
Courant de charge maximal 2 A
Fréquence RF 433 MHz
Type de codage Code d’apprentissage EV1527
Dimensions du récepteur (L x l x H) 31 mm x 15 mm x 4 mm (environ 1,2 x 0,6 x 0,2 pouces)
Dimensions de l’émetteur (L x l x H) 62 mm x 30 mm x 13 mm (environ 2,4 x 1,2 x 0,5 pouces)
Pile de l’émetteur 2x CR2016 (incluses)
Nombre maximal d’émetteurs pris en charge (par récepteur) 15 pièces
Distance de contrôle (zone dégagée) Jusqu’à 40 mètres
Modes de fonctionnement Impulsionnel, Bascule, Verrouillé, Temporisé

Détail du produit

  • 2 x Modules récepteurs – mini taille (31x15x4mm) avec antenne en spirale, bouton d’apprentissage, voyant lumineux
  • 2 x Émetteurs – style porte-clés avec boutons ‘A’ et ‘B’, alimentés par 2 piles CR2016 (incluses)
  • Bornes du récepteur : IN+ (entrée positive), IN- (entrée négative), OUT+ (sortie positive), OUT- (sortie négative)

Schéma de câblage

  • Entrée d’alimentation : Connectez CC 3,6 V-30 V à IN+ (positif) et IN- (négatif)
  • Sortie de l’appareil : Connectez l’appareil cible (par exemple, lumière LED, serrure électrique) à OUT+ et OUT-
  • Courant de charge maximal : 2 A

Avertissement

  • Assurez-vous que la tension d’alimentation correspond à la plage spécifiée du récepteur (CC 3,6 V-30 V).
  • Ne dépassez pas le courant de charge maximal de 2 A.
  • Débranchez l’alimentation avant d’effectuer tout câblage ou entretien.
  • Gardez l’appareil à l’abri de l’eau et des environnements très humides.
  • N’essayez pas de démonter ou de modifier l’appareil.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, reprogrammez-les.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur à distance est faible.

Mode de fonctionnement

Le mode par défaut est le Mode Verrouillé. Suivez les étapes de programmation ci-dessous pour changer de mode.

Mode Impulsionnel

Appuyez et maintenez un bouton → l’appareil s’ALLUME
Relâchez le bouton → l’appareil s’ÉTEINT

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 1 fois. Le voyant lumineux s’allumera.
  2. Appuyez sur n’importe quel bouton de l’émetteur. Le voyant lumineux clignotera puis s’éteindra. Réussi.

Mode Bascule

Appuyez une fois sur un bouton → l’appareil s’ALLUME
Appuyez à nouveau sur le même bouton → l’appareil s’ÉTEINT

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 2 fois. Le voyant lumineux s’allumera.
  2. Appuyez sur n’importe quel bouton de l’émetteur. Le voyant lumineux clignotera puis s’éteindra. Réussi.

Mode Verrouillé

Appuyez sur le bouton MARCHE (par exemple, ‘A’) → l’appareil s’ALLUME
Appuyez sur le bouton ARRÊT (par exemple, ‘B’) → l’appareil s’ÉTEINT

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 3 fois. Le voyant lumineux s’allumera.
  2. Appuyez sur le bouton MARCHE de l’émetteur.
  3. Appuyez sur le bouton ARRÊT de l’émetteur. Le voyant lumineux clignotera puis s’éteindra. Réussi.

Mode Temporisé

Appuyez sur un bouton → l’appareil s’ALLUME et s’ÉTEINT automatiquement après un délai défini

Options de temporisation :

  • Appuyez 4 fois sur le bouton d’apprentissage : délai de 5 secondes
  • Appuyez 5 fois sur le bouton d’apprentissage : délai de 10 secondes
  • Appuyez 6 fois sur le bouton d’apprentissage : délai de 15 secondes
  • Appuyez 7 fois sur le bouton d’apprentissage : délai de 20 secondes

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage le nombre de fois souhaité (4, 5, 6 ou 7). Le voyant lumineux s’allumera.
  2. Appuyez sur n’importe quel bouton de l’émetteur. Le voyant lumineux clignotera puis s’éteindra. Réussi.

Réinitialisation

Pour effacer tous les émetteurs appairés d’un récepteur, appuyez sur le bouton d’apprentissage 8 fois. Le voyant lumineux clignotera 8 fois puis s’éteindra, indiquant que tous les émetteurs stockés ont été effacés.

Dépannage

Si le récepteur et l’émetteur ne peuvent pas fonctionner normalement, essayez les étapes suivantes :

  • L’appareil ne répond pas : Vérifiez le câblage et l’alimentation (le voyant lumineux doit clignoter). Assurez-vous que les piles de l’émetteur ne sont pas déchargées. Vérifiez le bon appairage. Vérifiez la distance et les obstacles.
  • Fonctionnement intermittent : Assurez-vous que l’antenne n’est pas obstruée. Minimisez les interférences RF.
  • L’appareil s’ALLUME/ÉTEINT de manière inattendue : Peut indiquer des interférences ou un mode incorrect. Réappairez et sélectionnez le mode correct.
  • Le module récepteur chauffe : Le courant de l’appareil connecté dépasse la charge maximale de 2 A. Réduisez la charge.

Entretien

  • Remplacement de la pile (émetteur) : Remplacez par 2 piles CR2016 lorsque la portée diminue. Ouvrez le boîtier, remplacez en respectant la polarité correcte.
  • Soins généraux : Gardez au sec et à l’abri des températures extrêmes. Évitez les chutes. Nettoyez avec un chiffon doux et sec. N’utilisez pas de produits chimiques agressifs.
