SWITNEX AC85-250V Universal Wireless Remote Control Switch User Manual

13 janvier 2026

Manuel d’Utilisation de l’Interrupteur Universel sans Fil SWITNEX AC85-250V

Données Techniques
Technologie de Connectivité Radiofréquence (433MHz)
Tension d’Entrée du Récepteur CA 85V-250V
Courant Maximal 30A
Portée Maximale 50 mètres (164 pieds) sans obstacles
Nombre de Boutons (Télécommande) 2 (ON/OFF)
Nombre Maximal d’Émetteurs Pris en Charge 20 pièces
Fréquence RF 433MHz
Encodage Pris en Charge Code apprenant 1527, Code fixe 2262
Mode de Fonctionnement RF Réception sans fil superhétérodyne ASK
Température de Fonctionnement -30~+80
Sensibilité de Réception >97dbm
Courant de Repos <5MA

Détail du Produit

  • Unité réceptrice comprend : antenne pour la réception du signal, boîtier de protection, voyant lumineux, bouton d’apprentissage pour la programmation
  • Télécommande dispose de : boutons en silicone ‘ON’ et ‘OFF’, cadre chromé, porte-clés métallique pour la portabilité
  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Type de Sortie : Sortie active (ou sortie passive / contacts secs selon le cas)

Schéma de Câblage

Avertissement

  • Débranchez toujours l’alimentation avant d’effectuer tout câblage ou entretien.
  • Assurez-vous que toutes les connexions sont sécurisées et correctement isolées pour éviter les courts-circuits.
  • Ne dépassez pas le courant nominal maximal de 30A pour le relais.
  • Utilisez l’appareil dans la plage de tension spécifiée de CA 85V-250V.
  • Gardez l’appareil à l’écart de l’eau et des environnements très humides.
  • Si vous n’êtes pas sûr du câblage électrique, consultez un électricien qualifié.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, veuillez les reprogrammer.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la batterie à temps lorsque la tension de l’émetteur distant est faible pour obtenir une transmission de signal plus forte.
  • Étirez légèrement l’antenne du récepteur pour une meilleure réception du signal.

Mode de Fonctionnement

Mode Momentané (Mode 1)

Appuyez et maintenez le bouton de la télécommande → le relais s’allume (sortie ON)
Relâchez le bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 1 fois. Le voyant lumineux clignotera une fois.
  2. Appuyez sur n’importe quel bouton de votre télécommande. Le voyant lumineux clignotera trois fois, confirmant l’appairage réussi en Mode Momentané.

Mode Bascule (Mode 2)

Appuyez une fois sur le bouton de la télécommande → le relais s’allume (sortie ON)
Appuyez à nouveau sur le même bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 2 fois. Le voyant lumineux clignotera deux fois.
  2. Appuyez sur n’importe quel bouton de votre télécommande. Le voyant lumineux clignotera trois fois, confirmant l’appairage réussi en Mode Bascule.

Mode Verrouillé (Mode 3)

Appuyez sur le bouton ON → le relais s’allume
Appuyez sur le bouton OFF → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 3 fois. Le voyant lumineux clignotera trois fois.
  2. Appuyez sur le bouton ON de votre télécommande.
  3. Appuyez sur le bouton OFF de votre télécommande. Le voyant lumineux clignotera trois fois, confirmant l’appairage réussi en Mode Verrouillé.

Mode Temporisé (Mode 4/5/6/7)

Appuyez sur le bouton de la télécommande → le relais s’allume (sortie ON)
Après le délai défini, le relais s’éteint automatiquement

Options de délai :

  • Mode 4 (appuyez 4 fois sur le bouton d’apprentissage) : délai de 5 secondes
  • Mode 5 (appuyez 5 fois sur le bouton d’apprentissage) : délai de 10 secondes
  • Mode 6 (appuyez 6 fois sur le bouton d’apprentissage) : délai de 15 secondes
  • Mode 7 (appuyez 7 fois sur le bouton d’apprentissage) : délai de 20 secondes

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur le nombre de fois souhaité (4, 5, 6 ou 7). Le voyant lumineux clignotera en conséquence.
  2. Appuyez sur n’importe quel bouton de votre télécommande. Le voyant lumineux clignotera trois fois, confirmant l’appairage réussi en Mode Temporisé.

Réinitialisation

Appuyez sur le bouton d’apprentissage du récepteur 8 fois. Le voyant lumineux clignotera huit fois puis s’éteindra, indiquant une réinitialisation réussie. Après la réinitialisation, la télécommande ne fonctionnera plus jusqu’à ce qu’elle soit ré-appairée.

Dépannage

Si le récepteur et l’émetteur ne peuvent pas fonctionner normalement, essayez les étapes suivantes :

  • La télécommande ne répond pas : Assurez-vous que le récepteur est sous tension et que la télécommande a une batterie fonctionnelle. Si le récepteur a été récemment réinitialisé, ré-appairez la télécommande en suivant les instructions de programmation.
  • L’appareil ne s’allume/éteint pas : Vérifiez toutes les connexions de câblage pour leur serrage et une isolation correcte. Vérifiez que l’alimentation du récepteur est active et dans la plage de tension spécifiée (CA 85V-250V).
  • Portée réduite de la télécommande : De grands objets métalliques, des murs épais ou d’autres appareils radiofréquence peuvent interférer avec le signal. Essayez de repositionner le récepteur ou la télécommande.
  • Le voyant lumineux ne clignote pas pendant la programmation : Assurez-vous d’appuyer correctement sur le bouton d’apprentissage et pendant la durée appropriée spécifiée pour chaque mode.
  • Vérification de la batterie : La LED indicatrice sur l’émetteur distant ne s’allume pas ou est faiblement allumée – remplacez la batterie.

Entretien

  • Gardez le récepteur et la télécommande propres et exempts de poussière et de débris.
  • Évitez d’exposer les appareils à des températures extrêmes, à la lumière directe du soleil ou à l’humidité.
  • Remplacez la batterie de la télécommande lorsque ses performances se dégradent.
  • Vérifiez périodiquement les connexions de câblage pour tout signe d’usure ou de dommage.
