1 - SWITNEX 2204 Universal Wireless Remote Control Instruction Manual

Manuel d’instructions de la télécommande universelle sans fil SWITNEX 2204

Données techniques
Tension de fonctionnement CA 85V~250V
Tension d’entrée/sortie 1~250V
Type de sortie Sortie passive
Courant de repos <5MA
Courant maximal 10A
Fréquence RF 433 MHz
Température de fonctionnement -30~+80
Sensibilité de réception >97 dbm
Nombre de télécommandes stockables 20 pièces
Encodage supporté Code d’apprentissage 1527, code fixe 2262
Mode de fonctionnement RF Réception sans fil superhétérodyne ASK
Portée de réception Espace libre de plus de 50 mètres
Mode de fonctionnement de la télécommande Mode impulsionnel / Mode bascule / Mode verrouillé

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée

Schéma de câblage

Avertissement

  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, veuillez les reprogrammer.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la batterie à temps lorsque la tension de l’émetteur est faible pour obtenir une transmission de signal plus forte.
  • Étirez légèrement l’antenne du récepteur pour une meilleure réception du signal.
  • L’émetteur doit avoir 5 boutons ou plus si vous souhaitez le configurer en mode verrouillé.
  • Le type de sortie est une sortie passive / contacts sans potentiel.

Mode de fonctionnement

Mode impulsionnel

Maintenez enfoncé le bouton « A » → le relais « 1 » s’allume
Relâchez le bouton « A » → le relais « 1 » s’éteint

Comment programmer :

  1. Appuyez 1 fois sur le bouton d’apprentissage (sur le récepteur). Le voyant LED du récepteur s’allume.
  2. Appuyez sur le bouton « A » de l’émetteur. Le voyant LED du récepteur clignote plusieurs fois puis s’éteint. Réussi.

Mode bascule

Appuyez sur le bouton « A » → le relais « 1 » s’allume
Appuyez à nouveau sur le bouton « A » → le relais « 1 » s’éteint

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage (sur le récepteur). Le voyant LED du récepteur s’allume.
  2. Appuyez sur le bouton « A » de l’émetteur. Le voyant LED du récepteur clignote plusieurs fois puis s’éteint. Réussi.

Mode verrouillé

Appuyez sur le bouton « A » → le relais « 1 » s’allume
Appuyez sur le bouton « B » → le relais « 2 » s’allume, et le relais « 1 » s’éteint en même temps

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage (sur le récepteur). Le voyant LED du récepteur s’allume.
  2. Appuyez sur le bouton « A » de l’émetteur. Le voyant LED du récepteur clignote plusieurs fois puis s’éteint. Réussi.

Réinitialisation

Appuyez 8 fois sur le bouton d’apprentissage (sur le récepteur). Le voyant LED du récepteur clignote plusieurs fois puis s’éteint. Réussi.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Vérifiez si la batterie est épuisée. Le voyant LED de l’émetteur ne s’allume pas ou est faiblement allumé.
  • Vérifiez si votre récepteur est correctement câblé. Assurez-vous que le câblage est correct.
  • Reprogrammez le récepteur et l’émetteur. Cela résout généralement de nombreux problèmes.
  • Si le problème persiste, veuillez nous contacter.

Contact

  • Email : support@switnex.com
  • WhatsApp : +86 15812381273

Si vous avez des questions sur les produits, veuillez d’abord nous contacter. Nous ferons de notre mieux pour résoudre votre problème. Merci.

2 - SWITNEX DC 12V Wireless Relay Remote Control Switch User Manual

Manuel d’utilisation du commutateur relais sans fil SWITNEX DC 12V

Données techniques
Numéro de modèle 1204
Tension d’entrée / sortie 1V-250V
Tension de fonctionnement DC 12V
Courant nominal 10 Ampères
Fréquence RF 433MHz
Sensibilité de réception >97dBm
Code de puce EV1527 (Code d’apprentissage)
Portée de la télécommande Jusqu’à 50 mètres (zone dégagée)
Nombre de relais 4
Durée de vie du relais Plus de 100 000 utilisations
Type de connecteur Borne à vis
Matériau de contact Alliage de cuivre
Type de contact Normalement fermé (NF), Commun (COM), Normalement ouvert (NO)
Type de montage Montage en surface
Dimensions du produit 2,95 x 2,17 x 1,18 pouces
Poids du produit 5,93 onces
Piles (émetteurs) 2 piles CR2 (incluses)

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée

Schéma de câblage

Avertissement

  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, veuillez les reprogrammer.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur est faible pour obtenir une transmission de signal plus forte.
  • Étirez légèrement l’antenne du récepteur pour une meilleure réception du signal.
  • Assurez-vous que l’alimentation est coupée avant d’effectuer toute connexion de câblage.
  • Le type de sortie est une sortie passive / contacts sans potentiel.

Mode de fonctionnement

Mode Momentané

Appuyez et maintenez un bouton → le relais correspondant s’allume
Relâchez le bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 1 fois. Le voyant LED du récepteur s’allumera.
  2. Appuyez sur le bouton souhaité (par exemple, ‘A’) sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Bascule

Appuyez sur un bouton → le relais correspondant s’allume
Appuyez à nouveau sur le même bouton → le relais s’éteint

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 2 fois. Le voyant LED s’allumera.
  2. Appuyez sur le bouton souhaité sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Verrouillé

Appuyez sur le bouton ‘A’ → Le relais 1 s’allume (Le relais 2 s’éteint s’il était allumé)
Appuyez sur le bouton ‘B’ → Le relais 2 s’allume, et le relais 1 s’éteint en même temps

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage (sur le récepteur) 3 fois. Le voyant LED s’allumera.
  2. Appuyez sur le bouton souhaité sur l’émetteur. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi.

Mode Mixte

Pour des configurations avancées (par exemple, 2 momentanés + 2 bascules ; 2 momentanés + 2 verrouillés ; 2 bascules + 2 verrouillés), appuyez sur le bouton d’apprentissage 4, 5 ou 6 fois respectivement, puis appuyez sur les boutons correspondants de la télécommande comme indiqué.

Réinitialisation

Appuyez sur le bouton d’apprentissage (sur le récepteur) 8 fois. Le voyant LED clignotera plusieurs fois puis s’éteindra. Réussi. (Tous les émetteurs appairés seront effacés.)

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Vérifiez si la pile est épuisée. Le voyant LED de l’émetteur ne s’allume pas ou est faible. Remplacez par des piles CR2 neuves.
  • Vérifiez si votre récepteur est correctement câblé. Assurez-vous que le câblage vers les bornes NC, COM, NO est correct.
  • Assurez-vous que le récepteur est à portée (jusqu’à 50 mètres en zones dégagées) et que l’antenne n’est pas obstruée.
  • Évitez de placer le récepteur près d’autres sources de signaux RF puissantes qui pourraient causer des interférences.
  • Reprogrammez le récepteur et l’émetteur. Cela peut généralement résoudre de nombreux problèmes.
  • Si le problème persiste, veuillez nous contacter.

3 - SWITNEX Wireless DC Motor Remote Control Switch User Manual

Manuel d’utilisation de l’interrupteur sans fil pour moteur à courant continu SWITNEX

Données techniques
Tension d’entrée CC 12V-80V
Charge maximale (résistive) 10 Ampères
Charge maximale (inductive) 5 Ampères
Fréquence 433 MHz
Modes de fonctionnement Momentané, Bascule, Verrouillé
Mémoire de l’émetteur Jusqu’à 20 émetteurs
Distance de contrôle 20-50 mètres (zone dégagée)
Durée de vie du relais >100 000 fois
Poids de l’article 4,2 onces
Dimensions du colis 4,02 x 3,74 x 1,57 pouces
Piles 2 piles 12V (incluses)

Détail du produit

  • Bouton d’apprentissage sur le récepteur – pour programmer les modes de fonctionnement et réinitialiser
  • Voyant lumineux sur le récepteur – fournit un retour visuel

Schéma de câblage

  • Entrée : Alimentation CC 12V-80V (rouge : positif, noir : négatif)
  • Sortie : Vers le moteur à courant continu (rouge : positif du moteur, noir : négatif du moteur)
  • Pour les applications de treuil : Voir le schéma de câblage du relais solénoïde spécialisé pour treuil.

Avertissement

  • Assurez-vous que la tension de l’alimentation correspond à la plage de tension spécifiée du récepteur (CC 12V-80V).
  • Ne dépassez pas la charge résistive maximale de 10A (charge inductive 5A) pour le relais.
  • Débranchez l’alimentation avant d’effectuer tout câblage ou entretien pour éviter les chocs électriques.
  • Gardez l’appareil à l’écart de l’eau et des environnements très humides.
  • N’essayez pas de démonter ou de modifier l’appareil, car cela pourrait annuler la garantie et présenter des risques de sécurité.
  • Ce produit est destiné à être utilisé uniquement avec des moteurs à courant continu.

Mode de fonctionnement

Le produit est généralement préprogrammé en mode Verrouillé. Vous pouvez changer le mode en suivant les étapes de programmation ci-dessous.

Mode Momentané

Appuyez et maintenez le bouton Haut (▲) → le moteur fonctionne en avant
Relâchez le bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 1 fois. Le voyant lumineux clignotera une fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant lumineux clignotera, confirmant la programmation réussie.

Mode Bascule

Appuyez une fois sur le bouton Haut (▲) → le moteur démarre (en avant)
Appuyez à nouveau sur le même bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 2 fois. Le voyant lumineux clignotera deux fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant lumineux clignotera, confirmant la programmation réussie.

Mode Verrouillé

Appuyez sur Haut (▲) → le moteur tourne en avant
Appuyez sur Bas (▼) → le moteur tourne en arrière
Appuyez sur Arrêt (■) → le moteur s’arrête

Comment programmer :

  1. Appuyez sur le bouton d’apprentissage du récepteur 3 fois. Le voyant lumineux clignotera trois fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur (programmer la rotation avant).
  3. Appuyez sur le bouton Bas (▼) de l’émetteur (programmer la rotation arrière).
  4. Appuyez sur le bouton Arrêt (■) de l’émetteur (programmer la fonction d’arrêt). Le voyant lumineux clignotera, confirmant la programmation réussie.

Changer la direction du moteur (Avancé)

Si le moteur tourne dans le sens opposé à la direction souhaitée pour les boutons Haut/Bas, appuyez sur le bouton d’apprentissage 7 fois. Cela inversera la polarité de sortie.

Réinitialisation

Pour effacer tous les émetteurs programmés et réinitialiser le récepteur à l’état par défaut, appuyez sur le bouton d’apprentissage 8 fois. Le voyant lumineux clignotera pour confirmer. Après la réinitialisation, aucune télécommande ne pourra faire fonctionner le récepteur jusqu’à ce qu’elle soit reprogrammée.

Dépannage

Problème Cause possible Solution
Le moteur ne répond pas à la télécommande Pas d’alimentation sur le récepteur ; Piles de l’émetteur faibles/déchargées ; Émetteur non programmé ; Récepteur réinitialisé Vérifier l’alimentation ; Remplacer les piles de l’émetteur ; Reprogrammer l’émetteur (voir Mode de fonctionnement)
Le moteur tourne dans le mauvais sens Câblage incorrect ; Polarité du moteur inversée Vérifier le câblage (voir Schéma de câblage) ; Utiliser la fonction de changement de direction du moteur (appuyer 7 fois sur le bouton d’apprentissage)
Portée de la télécommande réduite Pile de l’émetteur faible ; Interférences environnementales ; Obstructions Remplacer les piles de l’émetteur ; Minimiser les sources d’interférences ; Assurer une ligne de vue dégagée si possible
Le moteur tourne en continu ou ne s’arrête pas Mode de fonctionnement programmé incorrect ; Bouton de l’émetteur défectueux Vérifier et reprogrammer le mode souhaité ; Tester avec un autre émetteur si disponible

Entretien

  • Gardez le récepteur et les émetteurs propres et secs.
  • Vérifiez régulièrement les connexions de câblage pour détecter tout desserrage ou corrosion.
  • Remplacez les piles de l’émetteur lorsque le voyant lumineux s’affaiblit ou que la portée diminue. Les émetteurs utilisent des piles 12V.
  • N’exposez pas les appareils à des températures extrêmes ou à la lumière directe du soleil pendant des périodes prolongées.

  • WhatsApp : +86 15812381273 Référez-vous à l’emballage du produit ou au site Web du détaillant pour les coordonnées du service client.

Si vous avez des questions sur les produits, veuillez d’abord nous contacter. Nous ferons de notre mieux pour résoudre votre problème. Merci.

4 - SWITNEX RF 433MHz Wireless Light Switch System User Manual

Manuel d’utilisation du système d’interrupteur sans fil SWITNEX RF 433 MHz

Données techniques
Numéro de modèle 750828381477
Dimensions du produit (interrupteur) 8,8 x 8,8 x 2,3 cm
Poids du produit (interrupteur) 60 grammes
Dimensions du récepteur 4,7 x 4,2 x 2,3 cm
Tension de fonctionnement (récepteur) CA 85 V ~ 250 V
Courant nominal (récepteur) 10 A
Fréquence RF 433 MHz
Code d’apprentissage EV1527
Pile de l’interrupteur 1 x 12 V 27A (incluse)
Durée de vie de l’interrupteur Plus de 500 000 clics
Durée de vie du relais du récepteur Plus de 400 000 utilisations
Matériau Plastique
Type d’interrupteur Bouton poussoir
Type de borne Vis
Pays d’origine Chine

Détail du produit

  • Bornes du récepteur : Entrée L / Entrée N (depuis la source d’alimentation), Sortie L / Sortie N (vers l’appareil)
  • Bouton d’apprentissage sur le récepteur – pour l’appairage et la réinitialisation
  • Voyant lumineux sur le récepteur – fournit un retour visuel pendant la programmation
  • Antenne sur le récepteur – peut être étendue pour un signal plus fort

Schéma de câblage

Avertissement

  • Débranchez toujours l’alimentation au niveau du disjoncteur avant d’installer ou d’entretenir tout composant électrique.
  • L’installation doit être effectuée par un électricien qualifié ou conformément aux codes électriques locaux.
  • Ne dépassez pas la charge maximale nominale de 10 A pour le récepteur.
  • Assurez-vous que toutes les connexions de fils sont sécurisées pour éviter les risques électriques.
  • Gardez l’appareil à l’abri de l’eau et des températures extrêmes.
  • L’interrupteur sans fil ne nécessite aucun câblage – peut être monté avec du ruban adhésif ou des vis.

Mode de fonctionnement

Mode Bascule

Appuyez sur le bouton de l’interrupteur sans fil → la lumière s’allume
Appuyez à nouveau sur le même bouton → la lumière s’éteint

Comment programmer (appairage) :

  1. Assurez-vous que le récepteur est sous tension.
  2. Appuyez sur le bouton d’apprentissage du récepteur 2 fois. Attendez 3 secondes. Le voyant lumineux du récepteur clignotera.
  3. Appuyez sur le bouton de l’interrupteur sans fil. Attendez 3 secondes. Le voyant lumineux cessera de clignoter, indiquant un appairage réussi.

Scénarios de contrôle multiple

  • Plusieurs interrupteurs contrôlent une lampe : Appairez jusqu’à 10 interrupteurs sans fil avec un seul récepteur (configuration à 3 voies).
  • Un interrupteur contrôle plusieurs lampes : Appairez un seul interrupteur sans fil avec plusieurs récepteurs pour un contrôle simultané.

Réinitialisation

Appuyez sur le bouton d’apprentissage du récepteur 8 fois. Attendez 3 secondes. Le voyant lumineux clignotera rapidement puis s’éteindra, indiquant que tous les appareils appairés ont été effacés.

Dépannage

Si le récepteur et l’émetteur ne peuvent pas fonctionner normalement, essayez les étapes suivantes :

  • Réception de signal faible : Étendez l’antenne du récepteur. Assurez-vous que la pile de l’interrupteur n’est pas déchargée. Vérifiez que l’interrupteur et le récepteur sont à portée effective (jusqu’à 50 mètres en zone dégagée).
  • L’interrupteur ne répond pas : Vérifiez la pile 12 V 27A. Remplacez-la si nécessaire. Réappairez l’interrupteur avec le récepteur (voir Mode de fonctionnement > Comment programmer).
  • Le récepteur ne bascule pas : Confirmez que le câblage est correct (Entrée L/N vers la source d’alimentation, Sortie L/N vers l’appareil). Assurez-vous que la charge ne dépasse pas 10 A.
  • Réinitialisez le récepteur (appuyez 8 fois sur le bouton d’apprentissage) pour effacer tous les appairages, puis réappairez.

Entretien

  • Remplacement de la pile (interrupteur sans fil) : La pile 12 V 27A dure généralement environ 5 ans. Ouvrez soigneusement le boîtier de l’interrupteur, retirez l’ancienne pile, insérez-en une nouvelle avec la bonne polarité, et refermez solidement.
  • Nettoyage : Essuyez l’interrupteur et le récepteur avec un chiffon doux et sec. N’utilisez pas de nettoyants abrasifs et ne les immergez pas dans l’eau.
