1 - SWITNEX Wireless DC Motor Remote Control Switch User Manual

Manuel d’utilisation de l’interrupteur sans fil pour moteur à courant continu SWITNEX

Données techniques
Tension d’entrée CC 12V-80V
Charge maximale (résistive) 10 ampères
Charge maximale (inductive) 5 ampères
Fréquence 433 MHz
Modes de fonctionnement Momentané, Bascule, Verrouillé
Stockage des émetteurs Jusqu’à 20 émetteurs
Distance de contrôle 20-50 mètres (zone dégagée)
Durée de vie du relais >100 000 fois
Poids de l’article 4,2 onces
Dimensions du colis 4,02 x 3,74 x 1,57 pouces
Piles 2 piles 12V (incluses)

Détail du produit

  • Bouton d’apprentissage sur le récepteur – pour programmer les modes de fonctionnement et réinitialiser
  • Voyant lumineux sur le récepteur – fournit un retour visuel

Schéma de câblage

  • Entrée : Alimentation CC 12V-80V (rouge : positif, noir : négatif)
  • Sortie : Vers le moteur à courant continu (rouge : positif du moteur, noir : négatif du moteur)
  • Pour les applications de treuil : Voir le schéma de câblage spécialisé du relais solénoïde de treuil.

Avertissement

  • Assurez-vous que la tension d’alimentation correspond à la plage de tension spécifiée du récepteur (CC 12V-80V).
  • Ne dépassez pas la charge résistive maximale de 10 A (charge inductive 5 A) pour le relais.
  • Débranchez l’alimentation avant d’effectuer tout câblage ou entretien pour éviter les chocs électriques.
  • Gardez l’appareil à l’écart de l’eau et des environnements très humides.
  • N’essayez pas de démonter ou de modifier l’appareil, car cela pourrait annuler la garantie et présenter des risques de sécurité.
  • Ce produit est destiné à être utilisé uniquement avec des moteurs à courant continu.

Mode de fonctionnement

Le produit est généralement préprogrammé en mode Verrouillé. Vous pouvez changer de mode en suivant les étapes de programmation ci-dessous.

Mode Momentané

Maintenez enfoncé le bouton Haut (▲) → le moteur tourne en avant
Relâchez le bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez 1 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera une fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant clignotera, confirmant la programmation réussie.

Mode Bascule

Appuyez une fois sur le bouton Haut (▲) → le moteur démarre (en avant)
Appuyez à nouveau sur le même bouton → le moteur s’arrête

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera deux fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur. Le voyant clignotera, confirmant la programmation réussie.

Mode Verrouillé

Appuyez sur Haut (▲) → le moteur tourne en avant
Appuyez sur Bas (▼) → le moteur tourne en arrière
Appuyez sur Arrêt (■) → le moteur s’arrête

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera trois fois.
  2. Appuyez sur le bouton Haut (▲) de l’émetteur (programmer la rotation avant).
  3. Appuyez sur le bouton Bas (▼) de l’émetteur (programmer la rotation arrière).
  4. Appuyez sur le bouton Arrêt (■) de l’émetteur (programmer la fonction d’arrêt). Le voyant clignotera, confirmant la programmation réussie.

Changer la direction du moteur (Avancé)

Si le moteur tourne dans le sens opposé à la direction souhaitée pour les boutons Haut/Bas, appuyez 7 fois sur le bouton d’apprentissage. Cela inversera la polarité de sortie.

Réinitialisation

Pour effacer tous les émetteurs programmés et réinitialiser le récepteur à l’état par défaut, appuyez 8 fois sur le bouton d’apprentissage. Le voyant clignotera pour confirmer. Après la réinitialisation, aucune télécommande ne fera fonctionner le récepteur tant qu’elles ne seront pas reprogrammées.

Dépannage

Problème Cause possible Solution
Le moteur ne répond pas à la télécommande Pas d’alimentation au récepteur ; Piles de l’émetteur faibles/déchargées ; Émetteur non programmé ; Récepteur réinitialisé Vérifier l’alimentation ; Remplacer les piles de l’émetteur ; Reprogrammer l’émetteur (voir Mode de fonctionnement)
Le moteur fonctionne dans le mauvais sens Câblage incorrect ; Polarité du moteur inversée Vérifier le câblage (voir Schéma de câblage) ; Utiliser la fonction de changement de direction du moteur (appuyer 7 fois sur le bouton d’apprentissage)
Portée de la télécommande réduite Pile de l’émetteur faible ; Interférences environnementales ; Obstructions Remplacer les piles de l’émetteur ; Minimiser les sources d’interférences ; Assurer une ligne de vue dégagée si possible
Le moteur tourne en continu ou ne s’arrête pas Mode de fonctionnement mal programmé ; Bouton de l’émetteur défectueux Vérifier et reprogrammer le mode souhaité ; Tester avec un autre émetteur si disponible

Entretien

  • Gardez le récepteur et les émetteurs propres et secs.
  • Vérifiez régulièrement les connexions de câblage pour détecter tout desserrage ou corrosion.
  • Remplacez les piles de l’émetteur lorsque le voyant s’affaiblit ou que la portée diminue. Les émetteurs utilisent des piles 12V.
  • N’exposez pas les appareils à des températures extrêmes ou à la lumière directe du soleil pendant des périodes prolongées.

2 - SWITNEX DC 24V Wireless Relay Remote Control Switch User Manual

Manuel d’utilisation de l’interrupteur relais sans fil SWITNEX DC 24V

Données techniques
Tension de fonctionnement du récepteur DC 6V ~ 30V
Tension d’entrée / sortie 1 ~ 250V
Courant maximal 10A
Fréquence RF 433MHz
Encodage supporté Code d’apprentissage 1527
Sensibilité de réception >97dbm
Mode de fonctionnement RF Réception sans fil superhétérodyne ASK
Température de fonctionnement -30 ~ +80
Portée de réception Espace dégagé de plus de 50 mètres
Courant de repos <5 MA

Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Bouton d’apprentissage sur le récepteur – pour les modes de programmation et la réinitialisation
  • LED indicatrice sur le récepteur – fournit un retour visuel
  • Antenne sur le récepteur – à déployer pour une meilleure réception du signal

Schéma de câblage

Avertissement

  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, vous pouvez les reprogrammer vous-même.
  • Réinitialisez avant de changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la batterie à temps lorsque la tension de l’émetteur est faible pour obtenir une transmission de signal plus forte.
  • Déployez légèrement l’antenne sur le récepteur pour une meilleure réception du signal.
  • L’émetteur doit avoir 3 boutons ou plus si vous souhaitez configurer le mode verrouillé.
  • Le type de sortie est une sortie passive / contacts secs.

Mode de fonctionnement

Mode Momentané

Maintenez enfoncé le bouton A → le relais 1 s’allume
Relâchez le bouton A → le relais 1 s’éteint

Comment programmer :

  1. Appuyez une fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Mode Bascule

Appuyez sur le bouton A → le relais 1 s’allume
Appuyez à nouveau sur le bouton A → le relais 1 s’éteint

Comment programmer :

  1. Appuyez deux fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Mode Verrouillé

Appuyez sur le bouton A → le relais 1 s’allume
Appuyez sur le bouton B → le relais 2 s’allume, et le relais 1 s’éteint en même temps

Comment programmer :

  1. Appuyez trois fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Réinitialisation

Appuyez huit fois sur le bouton d’apprentissage du récepteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Vérifiez si la batterie est épuisée. La LED indicatrice de l’émetteur ne s’allume pas ou est faiblement allumée.
  • Vérifiez si votre récepteur est correctement câblé. Il est important de s’assurer que le câblage est correct.
  • Reprogrammez le récepteur et l’émetteur. Cela résout généralement de nombreux problèmes.
  • Si le problème persiste, veuillez nous contacter rapidement. Nous ferons de notre mieux pour résoudre votre problème.

Manuel d’utilisation de l’interrupteur radiofréquence SWITNEX

Données techniques

Portée de réception (espace dégagé) >50 mètres
Configuration des broches N / L
Mode de fonctionnement de la télécommande Momentané / Bascule / Verrouillé
Piles de l’émetteur 2x CR2016 (incluses)
Courant de commutation maximal 10 ampères
Dimensions du récepteur 70 x 38 x 21 mm

Détail du produit

  • Module récepteur – avec boîtier de protection, bouton d’apprentissage, voyant lumineux, antenne
  • 2 x Émetteurs – format porte-clés, chacun avec piles CR2016 incluses
  • NO : Broche normalement ouverte (sortie relais)
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Bornes d’alimentation : N (Neutre), L (Phase) – CA 85 V-240 V

Schéma de câblage

  • Connectez la source d’alimentation (CA 85 V-240 V) aux bornes d’entrée L et N
  • Connectez l’appareil (ex. : lampe) aux bornes de sortie (L et N)
  • Les contacts du relais (NO, COM, NC) sont sans potentiel

Avertissement

  • Débranchez toujours l’alimentation avant d’effectuer tout câblage ou entretien.
  • Ne dépassez pas la charge maximale de 1500 W ou 10 A.
  • Assurez-vous que la tension correspond à CA 85 V-240 V.
  • Tenez l’appareil à l’écart de l’humidité et des températures extrêmes.
  • Gardez les télécommandes hors de portée des enfants.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, reprogrammez-les.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur est faible.

Mode de fonctionnement

Ce produit est généralement préréglé en mode Bascule en usine. Suivez les étapes ci-dessous pour changer de mode.

Mode Momentané

Appuyez et maintenez un bouton → le relais s’active (appareil ALLUMÉ)
Relâchez le bouton → le relais se désactive (appareil ÉTEINT)

Comment programmer :

  1. Appuyez 1 fois sur le bouton d’apprentissage du récepteur.
  2. Attendez environ 3 secondes.
  3. Appuyez sur n’importe quel bouton de l’émetteur. Le voyant clignote. Réussi.

Mode Bascule

Appuyez une fois sur un bouton → le relais s’active (appareil ALLUMÉ)
Appuyez à nouveau sur le même bouton → le relais se désactive (appareil ÉTEINT)

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur.
  2. Attendez environ 3 secondes.
  3. Appuyez sur n’importe quel bouton de l’émetteur. Le voyant clignote. Réussi.

Mode Verrouillé

Appuyez sur le bouton ON → le relais s’active (appareil ALLUMÉ)
Appuyez sur le bouton OFF → le relais se désactive (appareil ÉTEINT)

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur.
  2. Attendez environ 3 secondes.
  3. Appuyez sur le bouton ON souhaité de l’émetteur.
  4. Appuyez sur le bouton OFF souhaité de l’émetteur. Le voyant clignote. Réussi.

Réinitialisation

Pour effacer tous les émetteurs appairés de la mémoire du récepteur, appuyez 8 fois consécutivement sur le bouton d’apprentissage. La réinitialisation est réussie. Après la réinitialisation, toutes les télécommandes précédemment appairées ne fonctionneront plus.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • L’appareil ne répond pas : Vérifiez l’alimentation (CA 85 V-240 V). Assurez-vous que les piles de la télécommande ne sont pas déchargées. Vérifiez que la télécommande est correctement programmée. Vérifiez qu’il n’y a pas d’obstructions ou une distance excessive.
  • Fonctionnement en mode incorrect : Réinitialisez le récepteur (appuyez 8 fois sur le bouton d’apprentissage) et reprogrammez le mode souhaité.
  • Portée faible : Déployez l’antenne du récepteur. Remplacez les piles de la télécommande. Réduisez les interférences provenant d’autres appareils RF.

Entretien

  • Remplacement des piles (émetteur) : Remplacez par 2 piles CR2016 lorsque la portée diminue ou que le voyant est faible. Assurez-vous de la polarité correcte.
  • Nettoyage : Essuyez le récepteur et les télécommandes avec un chiffon doux et sec. N’utilisez pas de nettoyants liquides ou de solvants.
  • Durabilité du relais : Évalué à plus de 400 000 opérations ; boutons de l’émetteur à plus de 500 000 clics.

Appuyez et maintenez un bouton → la sortie est active
Relâchez le bouton → la sortie s’éteint

Comment programmer :

  1. Appuyez 4 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton A de votre télécommande.
  3. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Momentané.

Mode Bascule

Appuyez une fois sur un bouton → la sortie s’allume
Appuyez à nouveau sur le même bouton → la sortie s’éteint

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton B de votre télécommande.
  3. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Bascule.

Appuyez sur le bouton B → la sortie s’éteint

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Appuyez sur le bouton A de votre télécommande (pour ALLUMER).
  3. Appuyez sur le bouton B de votre télécommande (pour ÉTEINDRE).
  4. Attendez environ 3 secondes. Le voyant clignotera, confirmant l’appairage réussi en mode Verrouillé.

Définir l’état par défaut (Allumé/Éteint)

Pour définir si le relais est par défaut ALLUMÉ ou ÉTEINT lors du rétablissement de l’alimentation :

  1. Appuyez 7 fois sur le bouton d’apprentissage du récepteur. Le voyant clignotera.
  2. Le récepteur basculera entre les états par défaut ALLUMÉ et ÉTEINT. Le voyant confirmera l’état par défaut sélectionné.

Réinitialisation

Pour effacer tous les codes de télécommande stockés dans le récepteur, appuyez 8 fois sur le bouton d’apprentissage. Le voyant clignotera, confirmant que tous les codes ont été effacés.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • L’appareil ne répond pas à la télécommande : Vérifiez que le récepteur est correctement alimenté (voyant allumé). Assurez-vous que la pile de la télécommande n’est pas déchargée. Vérifiez que la télécommande est correctement appairée. Effacez tous les codes et reprogrammez si nécessaire. Vérifiez les obstructions ou une distance excessive.
  • L’appareil s’allume/s’éteint de manière inattendue : Cela peut être dû à des interférences. Essayez d’effacer tous les codes et de réappairer. Assurez-vous qu’aucun autre appareil 433 MHz ne fonctionne à proximité.
  • Le voyant du récepteur ne s’allume pas : Vérifiez l’alimentation électrique et les connexions de câblage. Vérifiez que le disjoncteur n’est pas déclenché.

Entretien

Remplacement de la pile (télécommande) : La télécommande utilise une pile 27A 12V. Si le voyant ne s’allume pas ou si la portée diminue :

  1. Ouvrez soigneusement le boîtier de la télécommande.
  2. Retirez l’ancienne pile 27A 12V.
  3. Insérez une nouvelle pile 27A 12V en respectant la polarité.
  4. Refermez le boîtier solidement.

Nettoyage : Essuyez le récepteur et la télécommande avec un chiffon sec et doux. N’utilisez pas de nettoyants liquides ou de solvants.
